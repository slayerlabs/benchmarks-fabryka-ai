# Generative and agentic benchmarks

Generated by `python -m codesota.leaderboard`. [Back to the results](README.md).

Each benchmark has its own protocol, harness and settings, written down in its directory under [`research/api-benchmarks/`](../../research/api-benchmarks/). Values are copied from its `results/<model>.json`, not recomputed. Results marked * require verification: they come from a pull request that is still in review, or they are not the benchmark's main row, for the reason given below. "null": the model cannot run the benchmark; "not run": no score, by decision, for budget, or not yet.
